This needs a real connection to the Twitch API, which requires registering an app in the Twitch Developer Console and completing an OAuth login — that can't be faked with placeholder data.

To wire this up for real:

  1. Register an app at dev.twitch.tv to get a Client ID and Client Secret
  2. Add those as env vars (e.g. TWITCH_CLIENT_ID, TWITCH_CLIENT_SECRET)
  3. Add an OAuth login route and a server-side token exchange
  4. Use the Twitch API (stream status, channel info, etc.) from the server, same pattern as the rest of this app — never expose tokens to the browser
