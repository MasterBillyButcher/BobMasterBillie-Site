Nightbot

Not connected yet

Same story as Twitch — Nightbot has its own API and OAuth flow via the Nightbot API docs, which needs real credentials to work.

In the meantime, Custom Commands (in the sidebar) works as a plain reference list — jot down commands and responses there, then paste them into Nightbot's dashboard by hand.

To wire up a real connection later:

  1. Register an app with Nightbot to get a Client ID and Client Secret
  2. Add an OAuth login route and a server-side token exchange
  3. Call the Nightbot API from the server to read/sync commands directly
